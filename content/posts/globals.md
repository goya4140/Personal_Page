很多视觉语言模型并不是“看不见”图像，而是在生成答案的后半段逐渐把注意力从视觉 token 移向语言输出。于是，模型可能数错遮挡物、把阴天说成下雨，或在细粒度视觉问答中凭语言先验补出图片里没有的内容。**Test-Time Latent Computation to Improve Visual Perception in Multimodal Large Language Models** 研究的问题是：不训练新参数、不增加外部工具，能否让模型在生成时回到更有视觉证据的隐状态区域，再计算一次。

本文解读 Chen Yang、Zheng Fang、Wenqi Fan 与 Jun Xia 的 [Test-Time Latent Computation to Improve Visual Perception in Multimodal Large Language Models](https://arxiv.org/abs/2611.30480)（arXiv v1，2026-11-23）。论文提出训练免费的 **Lobals（Look Back in the Latent Space）**，并公开了[实现代码](https://github.com/wuycM/Lobals)。

## 一、课题解读：视觉理解为什么需要“再看一遍”

MLLM 通常先把图片编码为视觉 token，再与文本 token 一起经过多层 Transformer，最后生成答案。一次前向传播中，浅层更多负责聚合视觉信息，中间层进行跨模态融合，深层逐渐转向输出预测。若模型在深层过早依赖语言模式，表面流畅的答案可能不再紧贴图片。

这类问题在计数、空间关系、细粒度辨识和视觉幻觉中尤其明显。理想的测试时扩展不一定要输出更长的思维链，也可以在**隐藏状态空间**增加计算：保留当前语义状态，把某个与图像交互较强的层窗口重新运行，再继续生成。

## 二、相关文献解读：从 token 推理到 latent computation

| 方向 | 代表性思路 | 与 Lobals 的关系 |
| --- | --- | --- |
| 层间表征分析 | 研究不同深度如何逐步形成语义和预测 | 提供“层不是同质计算”的观察基础 |
| 训练式循环计算 | 通过共享或循环 Transformer 层增加有效深度 | Lobals 借鉴额外 latent computation，但不改参数、不训练 |
| 训练免费的深度适配 | 在冻结模型中跳过或重复连续层 | Lobals 将重复计算定位到视觉证据最强的窗口 |
| 视觉幻觉缓解 | 直接放大视觉 token 或进行对比解码 | Lobals 不改 attention 权重，而是重新打开视觉交互区域 |

因此，论文的差异不只是“多算几层”，而是提出两个条件：先找出不会破坏正常语言生成的**稳定可复用带**，再在每个生成步依据视觉 token attention 动态选择窗口。

## 三、研究问题解读：本文究竟要验证什么

下面是我们的阅读归纳：

1. MLLM 是否包含可以安全重复前向的连续层区域？如何识别它的边界？
2. 在这个区域中，按视觉 token attention 选择窗口，是否比固定或随机重复更可靠？
3. 这种额外 latent computation 能否同时改善通用视觉理解、幻觉抑制和视觉中心任务？
4. 增益是否值得付出的推理延迟，并且对窗口长度是否敏感？

## 四、方法解读：从稳定层带到 Lobals 解码

![Lobals 的隐空间回看示意](../assets/img/blog/globals/overview.png "图 1 · 普通前向只经过一次层堆栈；Lobals 从可复用区域末端取隐状态，回送到其中的一个窗口，再继续到输出层。来源：原论文 Figure 1，PDF 第 3 页；原图渲染。")

### 第一步：用流畅性筛出可复用层带

作者在 Qwen3-VL-2B/8B/32B 和 InternVL3.5-14B 上，从 COCO 抽取 500 张图，用“Describe the image”生成描述。对每个候选窗口，把某层后的隐状态送回更早的起始层，重新运行连续层，再恢复正常解码；如果任何样本出现重复、乱码或不流畅，就认为该范围会破坏生成。

得到的稳定区域分别是：Qwen3-VL-2B 的 **[4, 27]**、Qwen3-VL-8B 的 **[8, 35]**、Qwen3-VL-32B 的 **[8, 63]**、InternVL3.5-14B 的 **[8, 39]**。论文观察到，起点通常是第一次出现 attention sink 的层，终点是倒数第二层；最后一层直接连接 logits，重复它更容易扰乱输出。

![不同 MLLM 的隐空间回看流畅性](../assets/img/blog/globals/fluency-analysis.png "图 2 · 黄色表示 500 个样本均保持流畅，蓝色表示至少一个样本出现非流畅输出。稳定区域因模型而异。来源：原论文 Figure 2，PDF 第 4 页；原图渲染。")

在 Qwen3-VL-8B 中，稳定区域内重新运行后的隐状态平均余弦相似度为 **0.996**；回看第 7 层时降到 **0.671**，回看更早的 [1, 6] 区域时降到 **0.277**。这支持“中后层更像渐进式精炼区”的解释，但不等于证明它只承载视觉推理。

### 第二步：每个生成步计算视觉注意力

设可复用层带为 (mathcal{R}=[s,e])，当前生成步为 (t)，视觉 token 位置集合为 (mathcal{V})，第 (ell) 层有 (H) 个 attention head。作者定义视觉 token attention ratio：

\[
\alpha_t^{(\ell)}=\frac{1}{H}\sum_{h=1}^{H}\sum_{j\in\mathcal{V}}A_{t,h,j}^{(\ell)}.
\]

它表示当前 token 在该层分配给视觉证据的平均注意力比例。给定窗口长度 (k)，Lobals 枚举 (mathcal{R}) 内所有连续窗口，选择累计比例最大的窗口：

\[
W_t^*=\arg\max_{W\subseteq\mathcal{R},\,|W|=k}\sum_{\ell\in W}\alpha_t^{(\ell)}.
\]

这里的选择是**逐生成步**进行的，因此同一张图的不同输出 token 可以回看不同层窗口。

### 第三步：将末端隐状态回送到选中窗口

正常路径是从 (s) 一直运行到 (e)，再进入最终输出层。Lobals 先完成正常前向，取得 (e) 层后的隐状态 (mathbf h_t^{(e)})，然后把它送回选中窗口 (W_t^*=[a_t,b_t])，重新运行这些层，再把精炼后的状态交给 (e) 之后的最终层。它不改权重，也不调用额外视觉工具。

实现上，下一步仍使用正常前向产生的 KV cache；回看计算只修改用于当前 token 预测的隐状态，不把新 key/value 写回持久 cache。这让它保持标准自回归解码的一致性。

## 五、实验设计与结果：增益来自哪里，代价是多少

### 主实验：三种开源 MLLM、六个多模态基准

作者测试 Qwen3-VL-2B、Qwen3-VL-8B 和 InternVL3.5-14B，比较 Base、VCD、PAI、VAF 与 Lobals。任务覆盖通用理解（RealWorldQA、MMStar、MME）、视觉幻觉（POPE、MMHal-Bench）和视觉中心理解（MMVP）。所有实验在 NVIDIA H200 上以 temperature 0、top-p 1.0 运行；平均分中 MME 除以 2800，MMHal-Bench 除以 6。

| 模型 | 方法 | RealWorldQA | MMStar | MME | POPE | MMHal | MMVP | 平均 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Qwen3-VL-2B | Base | 63.92 | 53.46 | 2019.80 | 89.96 | 3.58 | 44.21% | 68.47 |
|  | Lobals | **64.71** | 54.64 | **2032.10** | **89.97** | **3.93** | 35.53% | **70.29** |
| Qwen3-VL-8B | Base | 69.02 | 63.59 | 2368.80 | 88.90 | 4.53 | 30.53% | 76.77 |
|  | Lobals | 69.93 | 64.22 | **2409.30** | 89.26 | 4.62 | **29.47%** | **78.13** |
| InternVL3.5-14B | Base | 69.02 | 67.03 | 2379.20 | 85.88 | 4.25 | 23.96% | 76.40 |
|  | Lobals | 69.93 | 67.09 | **2389.40** | 85.99 | **4.30** | 21.88% | **76.78** |

表中 MMHal 的数值是归一化后的分数，百分号指标按各基准定义读取；POPE 和 MMVP 是越高越好，MMHal 的 Hall. Rate 是越低越好。Lobals 在三个 backbone 上都获得最佳或并列最佳平均分，并且相对对应 Base 没有报告指标下降；但它不是每个单项都提升，例如 Qwen3-VL-2B 的 MMVP 从 44.21% 降为 35.53%。因此更准确的结论是**整体更稳定、更有竞争力**，而不是所有视觉任务都单调变好。

### 机制消融：额外计算本身有用，但视觉引导更稳

在 Qwen3-VL-8B 的 POPE 上，固定选窗口起点、中点、终点、随机窗口和视觉引导窗口，准确率/F1 分别为：

| 选择策略 | Accuracy | F1 |
| --- | ---: | ---: |
| Start | 89.08 | 88.44 |
| Middle | 89.01 | 88.45 |
| End | 88.26 | 87.32 |
| Random | 89.17 | 88.63 |
| Visually grounded（Lobals） | **89.26** | **88.75** |

跨三个模型和三个基准的九个设置中，Lobals 有 **8 个**超过随机窗口，且从未低于对应 Base；随机窗口则会让 Qwen3-VL-2B 在 RealWorldQA 和 POPE 上下降。这说明“在稳定带内多算一次”可能已经带来机会，但按视觉证据分配额外计算更可靠。

### 案例与注意力分析：回看如何减少视觉幻觉

![Lobals 的视觉问答案例](../assets/img/blog/globals/case-study-qwen.png "图 3 · 两个 MMHal-Bench 案例：Lobals 将牡蛎计数从 6 修正为 5，并避免把阴天无依据地推断为下雨。来源：原论文 Figure 4，PDF 第 7 页；原图渲染。")

在牡蛎计数案例中，Qwen3-VL-8B 基线数出 6 个，Lobals 数出 5 个并逐个按位置说明；在天气案例中，Qwen3-VL-2B 基线在“阴天”之外添加“可能下雨”，Lobals 更保守地停留在图中可见的阴云和漫射光线。这些是定性案例，不是额外的总体成功率。

注意力分析给出一个与机制一致的线索：Qwen3-VL-8B 的回看窗口 R13–R21 中，首 token 平均 attention 降到 **15.6%**，视觉 token attention 升到 **51.7%**。但作者明确提醒，attention 不是视觉 grounding 的因果测量，因此这里只能作为相关性证据。

### 效率与窗口长度：增益需要付出额外计算

Qwen3-VL-8B 有 36 层，主实验窗口 (k=9)。因为每个 token 需要额外回看 (k+1) 层，层级计算量约为 ((36+10)/36\approx1.28\) 倍。H200 上 MMHal-Bench 的端到端延迟从 **2.53 s** 增至 **4.30 s**（1.70×），输出吞吐从 **40.08** 降到 **25.56 token/s**，即保留基线的 63.8%。窗口更长不保证更好：Qwen3-VL-2B 在 (k=3) 最佳，Qwen3-VL-8B 在 (k=9) 更好，最优值依模型而变。

## 六、我们自己的思考

### 课题思考：这个领域在研究什么

这项工作属于测试时计算扩展：模型参数固定，但推理路径可以根据输入重新分配。它把“多想一会儿”具体化为对隐藏状态的局部重算，并将视觉理解问题连接到 Transformer 的层级功能结构。更一般地说，研究重点正在从是否拥有能力，转向如何在每个样本上把有限计算放到最需要的位置。

### 局限问题思考：目前还存在哪些问题

第一，视觉 attention ratio 是启发式指标，未必等于模型真正依赖的视觉证据；选中的窗口可能不是最优。第二，稳定带的起点依赖 attention sink，而未来架构可能弱化或消除这种模式。第三，主实验只有三个开源 backbone，且窗口长度和稳定区域需要按模型设定，跨架构自动迁移尚未解决。第四，平均分提升通常是小幅的，同时延迟增加 1.70×；如果任务更偏语言或输出很长，额外回看是否值得需要重新计算。

### 解决方案思考：这些问题有哪些解决方向

可以用梯度、遮挡、因果干预或多信号集成来选择窗口，检验“视觉相关”是否真的带来答案因果改善，而不只看 attention。稳定区域可以通过流畅性、隐状态相似度和输出一致性联合估计，并在新模型上自动校准。实验上应加入更多视觉编码器、架构和规模，报告每个任务的增益分布，而不只给平均分。最后，可以按 token 难度自适应决定是否回看、回看多长，并把准确率—幻觉—延迟画成 Pareto 曲线。

**一句话总结：** Lobals 不是让 MLLM 生成更长的文字，而是在生成过程中把隐状态送回“最看图”的中间层窗口再算一次；它在多个基准上带来稳定但并非全面的提升，代价是可控却真实存在的推理延迟。
